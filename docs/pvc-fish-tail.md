# PVC 凝胶人工肌肉驱动的仿生鱼尾

本科团队项目，2026 年 4 月的求真杯申报与汇报材料留有记录。此页公开技术路线摘要，供了解柔性驱动与机械设计方向；不将团队整体实验成果写成个人独立完成。

## 研究问题

使用 PVC 凝胶驱动单元代替传统刚性电机传动，使鱼尾形成可控制的周期摆动。项目关注材料、电极与叠层结构如何影响驱动器输出，以及驱动器与尾部骨架、柔性尾鳍之间的匹配。

## 材料中已形成的技术内容

- 由 PVC 薄膜、网孔阳极、平面阴极和叠层装配构成驱动单元的工艺路线。
- 电压、应变和应力之间关系的分析，以及驱动层数和几何参数的比较思路。
- 将驱动单元的收缩通过鱼尾骨架转化为弯曲与摆动，围绕摆幅、频率及推进效果组织测试。
- 已形成项目申报与汇报材料，覆盖制备、驱动性能、结构设计及测试方法。

## 公开材料范围

此次归档提供原有技术材料的整理摘要。完整团队实验数据、制造文件与可复现控制代码未在当前公开包中建立对应关系，因此不列出未经独立复核的推力、效率和个人实验指标。后续可补充本人负责环节的设计图、原始数据与程序，形成完整案例。
